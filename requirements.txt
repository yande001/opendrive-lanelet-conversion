# Python dependencies for the OpenDRIVE -> Lanelet2 conversion pipeline.
#
# crdesigner is the pinned git submodule (extern/commonroad-scenario-designer),
# installed editable so local edits to the autoware_dev fork take effect. It also
# supplies the heavy transitive deps (commonroad-io, lxml, pyproj, shapely, numpy,
# scipy, networkx, pyyaml, matplotlib, pandas, ...). Do NOT add a bare
# `commonroad-scenario-designer` line -- that pulls the PyPI release, which lacks
# the autoware_dev changes.
#
# The packages below are the ones the conversion scripts import directly; they are
# left unpinned here and resolved to exact versions in requirements.lock
# (generated with: uv pip compile requirements.txt -o requirements.lock).
